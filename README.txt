JACK VERBEL — PORTFOLIO
=======================

Upload the CONTENTS of this folder to the repo root (not the folder itself).

  index.html      home — statement + two project tiles
  watch.html      Movado 2025 case study
  wrench.html     Ingersoll Rand impact wrench case study
  about.html      bio, experience, education
  contact.html    contact details
  styles.css      the whole design system
  site.js         nav hairline + scroll reveals
  vercel.json     clean URLs (/watch instead of /watch.html)
  assets/         every image and the assembly video

The pages are GENERATED. Do not hand-edit the HTML — edit build.py in the
project root and re-run `python3 build.py`, or the next build will overwrite
your changes. Copy and structure both live in that one file.

Fonts load from Google Fonts (Space Grotesk + Space Mono). Nothing else is
fetched from outside.
